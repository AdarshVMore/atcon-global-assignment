Case Study – Full Stack Developer
Context
We are building modern AI and data-driven products focused on automation, integrations,
operational tooling, and scalable backend systems.
As part of this exercise, we would like you to design and build a lightweight recruitment
platform focused on job postings and candidate pipeline management.
Assignment
Applicant Tracking + Candidate Pipeline System
Build a small recruitment platform where users can:
• publish job openings and receive applications,
• parse and store candidate profiles and resumes,
• move candidates through configurable hiring stages,
• schedule interviews and record structured scorecards,
• and track time-to-hire and pipeline health.
The objective is to evaluate your ability to design and implement practical backend-heavy
systems with product-oriented thinking.
Expected Capabilities
The solution should demonstrate some or all of the following:
• Backend API design
• Authentication / authorization with recruiter roles
• Multi-stage workflow / state machine modelling
• File upload and resume parsing
• Duplicate candidate detection
• Background jobs / async processing
• Email or in-app notifications
• Audit trail of stage changes
• Database design
• Dashboard or lightweight UI
You are NOT expected to build a fully production-ready platform.
We are more interested in:
• architecture,
• prioritization,
• engineering reasoning,
• and implementation quality.
Please Include
1. Technical Overview
Explain:
• architecture decisions,
• frameworks/tools chosen,
• scalability considerations,
• and system design approach.
2. Assumptions & Tradeoffs
Please explain:
• assumptions made,
• limitations,
• and what you would improve with additional time.
3. Demonstration
Please provide:
• source code,
• setup instructions,
• and a short demo video or walkthrough if possible.
Evaluation Criteria
We will evaluate:
• backend engineering quality
• architecture & scalability thinking
• API design
• reliability considerations
• code structure
• product thinking
• communication & documentation
• practicality of implementation
Timeline
Please prepare your submission within 7 days of receiving this assignment.
