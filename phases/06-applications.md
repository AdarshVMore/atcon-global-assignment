# Phase 6 — Applications

[← Back to index](README.md)

## Goal

Allow candidates to apply to jobs and recruiters to manage applications.

### Tasks

- [ ] Apply to published job.
- [ ] Validate job status.
- [ ] Prevent duplicate application to same job.
- [ ] Create Application record.
- [ ] Get application.
- [ ] List applications for recruiter.
- [ ] List applications for candidate.
- [ ] Enforce candidate/application ownership.
- [ ] Enforce recruiter/job ownership.
- [ ] Implement deterministic candidate duplicate detection.
- [ ] Add application tests.
- [ ] Verify application transaction behavior.

### Verification

- Candidate can apply.
- Candidate cannot apply twice to the same job.
- Recruiter can view applicants for their jobs.
- Candidate can only access their own applications.
- Duplicate detection is predictable.
