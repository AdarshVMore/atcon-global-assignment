# Phase 4 — Job Management

[← Back to index](README.md)

## Goal

Allow recruiters to create and manage jobs and configurable stages. See
[architecture/data-model.md](../architecture/data-model.md#job-model).

### Tasks

- [ ] Create job.
- [ ] Update job.
- [ ] Archive/delete job where appropriate.
- [ ] Publish job.
- [ ] List jobs.
- [ ] Get job details.
- [ ] Create job stages.
- [ ] Update job stages where appropriate.
- [ ] Validate recruiter access.
- [ ] Add job tests.
- [ ] Add job-stage tests.

### Verification

- Recruiter can manage jobs.
- Candidates can view published jobs.
- Job stages are configurable.
- Job authorization works.
