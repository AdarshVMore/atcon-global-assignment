# Phase 11 — Interviews

[← Back to index](README.md)

## Goal

Implement interview scheduling and structured scorecards. See
[architecture/background-jobs.md](../architecture/background-jobs.md#interviews)
and [architecture/data-model.md](../architecture/data-model.md#interview-model).

### Tasks

- [ ] Schedule interview.
- [ ] Associate interview with application.
- [ ] Associate interviewer.
- [ ] Store scheduled time.
- [ ] Store meeting information.
- [ ] Implement rescheduling.
- [ ] Implement cancellation.
- [ ] Implement interview completion.
- [ ] Create structured scorecard.
- [ ] Submit scorecard.
- [ ] Prevent invalid duplicate scorecard submissions.
- [ ] Add interview tests.
- [ ] Add scorecard tests.

### Verification

- Recruiter can schedule interview.
- Interview is linked to application.
- Interview lifecycle is understandable.
- Scorecard is structured.
- Scorecard submission is authorized.
